# Butterflight

여행 전 설레는 아이디어를 스크랩북처럼 모으는 여행 앱입니다.

## 중간 점검 1차

- 메인 화면: 비행기 창문 카드로 아이디어 방 고르기 (방이 없으면 방 만들기)
- 아이디어 방 만들기: 여행지, 방 이름·날짜(선택), 혼자/함께
- 방 화면 전체가 스크랩북 게시판: 사진·제목·종류·메모·위치·링크·중요도로 아이디어 붙이기
- 카드 자유 배치(끌어 옮기기), 상세 보기 → 수정하기, 삭제
- 종류별 스티커 필터, 일정·여행 기록 탭(다음 단계에서 추가)

## 실행 방법

`index.html` 하나로 동작합니다. 브라우저로 열거나 정적 호스팅(Vercel 등)에 올리면 됩니다.

## 저장 방식

1차에서는 데이터를 브라우저(localStorage)에 저장합니다. 같은 기기·같은 브라우저에서만 보입니다.
2차에서 Supabase 서버 저장으로 바꿀 예정입니다.
